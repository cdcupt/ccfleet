Why we are evaluating Devin为什么评估 Devin

Pilot preparation — awaiting account verification. Devin is not yet available through CC Fleet. We have not completed an authenticated Claude-model task on a Fleet node.

试点准备中，等待账号验证。CC Fleet 尚未开放 Devin。我们还没有在 Fleet 节点上完成经过账号认证的 Claude 模型任务。

A third subscription option第三种订阅选择

Devin is a candidate because it offers Claude models in its own coding agent, an official Linux CLI, and a predictable base monthly fee. This could give Fleet users another way to run coding tasks on their own slot. See the official CLI guide and model guide.

我们评估 Devin，是因为它提供可使用 Claude 模型的自有编程智能体、官方 Linux 命令行客户端，以及明确的基础月费。这可能为 Fleet 用户在自己的槽位运行编程任务增加一种选择。详见官方CLI 指南和模型指南。

Devin CLI is a different application from Claude Code. Choosing a Claude model in Devin does not run the Claude Code application. The existing Fleet Connect Claude gateway does not accept Devin credentials. The pilot will use a separate Devin login and execution path.

Devin CLI 与 Claude Code 是不同的应用。在 Devin 中选择 Claude 模型，并不等于运行 Claude Code 应用。现有 Fleet Connect 的 Claude 网关不接受 Devin 凭证。试点将使用独立的 Devin 登录与执行路径。

Planned task flow: your task → Fleet front agent → a selected execution agent, such as official Claude Code or Devin. This unified task entry is a proposed extension. The current Claude model gateway does not yet delegate tasks to these agents.

规划中的任务流程：你的任务 → Fleet 前置智能体 → 选定的执行智能体，例如官方 Claude Code 或 Devin。统一任务入口属于规划中的扩展；现有 Claude 模型网关尚不能将任务委派给这些智能体。

Cognition also offers Outposts for running cloud-managed sessions on customer infrastructure. That is a separate option; this first pilot evaluates the local CLI.

Cognition 另有 Outposts，可让云端管理的会话在客户基础设施上执行。这是另一种方案；首个试点评估本地 CLI。

Base fee, then usage limits基础月费与用量限制

Checked October 18, 2026: Devin lists Pro at US$20/month and Max at US$200/month. Pro has daily and weekly quotas; Max has a larger weekly quota without a daily cap. Paid on-demand usage can add to the base fee. These are individual, single-user plans. See billing details and current pricing.

2026 年 10 月 18 日核对：Devin Pro 为每月 20 美元，Max 为每月 200 美元。Pro 有每日和每周额度；Max 的每周额度更高，没有每日上限。付费超额用量可能增加总账单。这两个套餐均为个人单用户订阅。详见计费说明与当前价格。

An existing Claude subscription may be the lower-cost choice; Devin would be an additional bill. We have not verified a savings advantage or a fixed amount of coding work per month.

已有的 Claude 订阅可能更省钱；Devin 会增加一笔订阅费用。我们尚未验证它能节省多少成本，也不承诺每月可完成固定数量的编程任务。

What a future Fleet service could include未来 Fleet 服务可能包含什么

Our interim proposal is to charge for Fleet compute and support while each customer buys and uses their own Devin account, subject to confirming the hosted-use arrangement with Cognition. A bundle that includes or resells Devin access requires written reseller or partner permission from Cognition.

过渡方案是仅收取 Fleet 计算资源与支持费用，每位客户自行购买并使用自己的 Devin 账号；托管使用安排仍需向 Cognition 确认。包含或转售 Devin 访问权的打包服务，必须先取得Cognition 的书面经销或合作授权。

The standard Acceptable Use Policy prohibits selling or reselling the service and sharing accounts or credentials. The Platform Terms grant non-transferable access for internal business use. We have no reseller permission to announce and no Devin package for sale.

标准可接受使用政策禁止销售或转售服务，以及共享账号或凭证。平台条款授予的访问权不可转让，且限内部业务使用。我们目前没有可公布的经销授权，也没有在售的 Devin 套餐。
