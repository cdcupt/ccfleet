Why we are evaluating Devin为什么评估 Devin

Devin is an operator-enabled pilot. The private own-slot route is working. Your account page offers it only after your own slot has been verified. Anthropic remains the default. The separate limited daily trial is offered only when Try Devin appears on your Fleet account. Follow that page instead of the paid-slot setup below.

Devin 是由运营方明确启用的试点。自有槽位的私有连接已经可以工作；只有自有节点通过验证后，你的账号页面才会提供这个选择。Anthropic 仍为默认服务。独立的每日限额试用，仅在账号页显示试用 Devin时提供；请按该页操作，不要套用下方的付费槽位设置。

Optional daily Devin trial可选每日 Devin 试用

When Try Devin appears: sign in to Fleet with Google, create a trial key, then copy its command into your local Claude Code terminal. No slot purchase or Devin login. This uses a separate Fleet-managed native worker, not another customer's private slot. Provider credentials are never given to visitors; local tools and history stay on your computer, while included model context is sent to Fleet and Devin.

Daily trial allowance: 100,000 per verified Fleet account, reset at 00:00 UTC. If native Devin omits only cache-read metering, the turn keeps a conservative 20,000-unit reservation (or its larger known subtotal). The account page separates complete reported tokens, partial readings and unmeasured reservations; missing usage is never assigned zero. This is not USD or an exact provider quota/token hard stop. Trial keys last 30 days across daily resets and can be revoked.

Optional Devin trial: the limited trial uses a Fleet-managed provider account, unlike private paid slots with your own provider sign-in. Your local Claude Code sends the current request and its included conversation/tool history to Fleet and Devin. A fresh worker HOME is used for every turn; after confirmed process cleanup and usage collection, its history and artifacts are removed. Trial accounting keeps account IDs, hashed keys and usage totals, not prompts or replies. Administrators technically control the worker. Do not send secrets. Your local Claude Code history remains on your computer.

The paid private-slot route below remains separate: bring your own provider account; native records can remain on that slot until it is cleared. No new app or change to the published Fleet client is required for the trial.

显示试用 Devin时：用 Google 登录 Fleet、创建试用密钥，然后在本地 Claude Code 终端粘贴命令。无需购买槽位或登录 Devin。试用使用独立的 Fleet 管理工作进程，不会借用其他用户的私人槽位，也不会将服务商凭证交给访客。本地工具及历史留在你的电脑，包含在模型请求中的内容会发送给 Fleet 和 Devin。

下文的付费私人槽位仍独立使用：自行准备服务商登录，原生记录可能保留到槽位清理。试用无需另装应用或修改已发布的 Fleet 客户端。

Trial limits and metering details试用限额与计量细节

The daily allowance is 100,000 per account and 1,000,000 shared, reset at 00:00 UTC. Fully metered usage is charged as reported; if only native cache-read metering is missing, up to 20,000 units stay conservatively held for that turn (or the larger known subtotal). This is not an exact token or USD hard cap. One global active turn, twenty turns/twenty reserved minutes per day; a busy worker asks you to wait. Unknown execution or cleanup pauses new work. Paid private slots and their own-provider subscriptions remain separate.

Trial requests including tools/history are at most 192 KiB. Each native turn has a forty-second generation deadline inside a sixty-second reservation. Per-account API throttling allows burst three and refills forty requests per minute; key replacement cannot bypass it. Complete input, output, cache-read and cache-creation counts settle actual reported usage including overshoot. The cache-read-only hold needs verified served-model evidence, a valid reply and confirmed process plus full artifact cleanup. Other missing usage, unknown identity, lost execution or uncertain cleanup pauses new work. Ambiguous model sends are never automatically replayed. max_tokens is context, not an upstream enforced output/spending cap.

每日每账号额度为 100,000，所有用户共享 1,000,000，UTC 零点重置。完整计量按已报告用量结算；只缺少原生缓存读取计量时，每轮保守保留最多 20,000 单位，已知部分更大则保留更多。这不是精确 token 或美元硬上限。全局同时仅一轮，每日最多二十轮、预留二十分钟；忙碌时请稍候。执行或清理不确定时暂停。付费私人槽位及自有服务商订阅仍独立使用。

含工具及历史的请求最多 192 KiB；每轮原生生成最多四十秒，包含在六十秒预留时间内。账号 API 限流允许瞬时三次、每分钟恢复四十次，更换密钥不能绕过。完整的输入、输出、缓存读取及创建数量按实际报告总数结算，超额也计入。仅缺缓存读取时，必须有已验证模型、有效回复、进程与全部产物已清理的证据，才可保守保留额度。其他计量、身份、执行或清理不确定时暂停新任务；发送情况不确定时绝不自动重放。max_tokens 仅作为上下文，不是上游强制输出或费用上限。

How it works它怎样工作

The Fleet API address and key token stay the same; the website provider setting chooses Anthropic or Devin. An internal MCP bridge carries tool requests back to Claude Code. Read, Edit and Bash run on your computer with Claude Code’s permissions.

Fleet API 地址和密钥保持不变，网站的提供商设置选择 Anthropic 或 Devin。内部 MCP 桥把工具请求送回 Claude Code，Read、Edit 和 Bash 由你的电脑执行，并遵守 Claude Code 的权限控制。

What the pilot proved试点验证了什么

An owner-pilot check through the public Fleet endpoint used Read, Edit and Bash and passed three local tests. All four streamed replies were verified as Opus 5.5 Max. Check your account page for current provider readiness.

This is native-agent compatibility mode: visible system instructions and history become labeled context for Devin CLI; its own harness instructions still apply. Images, documents and other unsupported features reject before launch. count_tokens is unsupported. max_tokens is passed as context, not an enforced output or spending cap. Universal Claude Code parity is unverified.

The local tool catalog supports up to 512 declared tools, including MCP tools, within the existing request and context size limits. Tool names must be unique and each input schema must describe an object. If a catalog is rejected, Fleet reports the specific count, name, schema or size problem without exposing tool contents.

The reviewed Devin bridge omits prior assistant private reasoning and signatures when continuing a Claude conversation. Visible text, local tool calls/results and turn order stay intact; a bridge note replaces a private-only assistant turn. Reasoning continuity is lost and answers may change. Unknown or malformed blocks and reasoning in user messages still reject.

Privacy: Saved files and local Claude Code history stay on your computer. File contents you send, selected context, replies and tool handoff records may also be stored on your slot by native Devin. Machine administrators (root) can read those records. They may remain until the slot is cleared; no retention period is guaranteed.

自有账号试点通过公开 Fleet 入口，使用 Read、Edit 和 Bash，通过了三个本地测试。四次流式回复均核实为 Opus 5.5 Max。连接前请查看账号页面上的服务就绪状态。

这是原生智能体兼容模式：可见的系统指令和历史记录作为带标签的上下文交给 Devin CLI，其自身运行框架的指令仍然生效。图片、文档等不支持的功能会在启动前拒绝；不支持 count_tokens。max_tokens 仅作为上下文传入，不是强制的输出或费用上限。尚未验证完整的 Claude Code 功能等价性。

本地工具列表最多支持 512 个已声明工具（含 MCP 工具），请求与上下文大小限制仍然适用。工具名称必须唯一，输入结构必须声明为对象。若列表被拒绝，Fleet 会明确说明数量、名称、结构或大小问题，不披露工具内容。

已审阅的 Devin 桥接在续接 Claude 对话时会省略助手先前的私有思考及签名，保留可见文本、本地工具调用／结果和轮次顺序；只有私有思考的助手轮次会替换为明确的桥接说明。思考过程无法延续，回答可能因此改变。未知或格式错误的内容块，以及用户消息中的思考块，仍会被拒绝。

隐私：保存的文件和本地 Claude Code 历史仍在你的电脑上。你发送的文件内容、选定上下文、回复及工具交接记录，也可能被原生 Devin 保存在槽位上。主机管理员（root）可以读取这些记录；记录可能保留到槽位清理时，不保证具体保留期限。

Two ways to pay for a Fleet slot槽位的两种付费方式

One month with Fleet credit. On Your slots, choose Add credit, select $10, $20, $50 or $100, then Continue to secure payment. Pay on Stripe and check your balance after payment is confirmed. Choose a slot and confirm its separate purchase. This buys one calendar month; renewal needs your confirmation. Adding credit does not buy or renew a slot.

用 Fleet 余额购买一个月。在我的槽位点击充值，选择 10、20、50 或 100 美元，再点击前往安全付款页面。到 Stripe 付款，确认后核对余额。随后另行选择槽位并确认购买，只支付一个日历月，需要时再自行确认续费。充值本身不会购买或续费槽位。

Optional monthly card payment. When a new slot offers Pay monthly, review the USD price, tick the monthly-payment agreement and complete the first payment on Stripe. Stripe shows the billing dates. Each slot has an independent plan: two slots mean two monthly payments. This option does not use Fleet credit. Existing slots, balances and prepaid time are not enrolled or converted automatically.

可选的银行卡月付。新槽位提供按月付款时，先核对美元月费，勾选同意每月付款，再到 Stripe 完成首笔付款。账单日期以 Stripe 显示为准。每个槽位独立付费，两个槽位就是两份月付计划。此方式不使用 Fleet 余额，也不会自动转换已有槽位、余额或预付费服务期。

For a confirmed monthly plan, open Monthly payments and choose Cancel renewal on that slot. Once confirmed, renewal stops after Stripe’s current billing period; access is limited to paid time. An unpaid invoice already issued may still be retried. Cancellation does not automatically void it or refund money. A pending cancellation is not yet confirmed. Payment review pauses new connections; you can still request cancellation. The general Stripe portal is paused while a review or cancellation is pending. Expiry does not automatically wipe files. Wait until the monthly plan and its paid time have both ended before explicitly returning the slot. Your own Claude or Devin plan is paid separately. Alipay is not available for Fleet credit. See Terms.

月付计划确认后，可在月付管理为对应槽位选择停止续费。取消确认后，续费在 Stripe 当前账期结束后停止，只能使用已付费的时间。已有未付款账单仍可能重试扣款；取消不会自动作废账单或退款。正在确认取消表示结果尚未确认。付款核查会暂停新连接，但仍可申请取消；核查或取消结果待确认期间，暂停通用 Stripe 管理入口。到期不会自动删除文件；如需归还槽位，请等月付计划与已付费服务时间都结束后，再明确确认归还。你自己的 Claude 或 Devin 订阅需要另付。Fleet 余额暂不支持支付宝，规则见服务条款。

Only one unfinished monthly checkout can be open at a time; paid plans remain independent. In Monthly payments, choose Continue checkout or Cancel checkout before starting another. Unpaid checkout closes only after Stripe confirms expiry. If payment already completed, you keep that paid month and confirmed cancellation stops future renewal; no automatic cash refund is issued. Keep checking a pending checkout instead of starting a replacement.

一次只能有一笔未完成的月付结账，已付费的计划仍各自独立。在“月付管理”选择继续付款或取消这次付款，再开始另一笔。未付款的页面只有在 Stripe 确认过期后才会关闭；若已经付款，已付费月份仍保留，取消确认后停止今后的续费，不会自动退款。结果待确认时请继续核对同一笔，不要另开一笔。

Use Devin with Claude Code怎样用 Claude Code 连接 Devin

Already Devin ready? Open Your slots → Use Devin on my computer. Follow the steps in order: update Fleet, save the connection, then start coding. A first-time computer without a working Fleet pairing can use the manual connection settings instead.

  1. Open Browse available slots, review the monthly price, confirm the purchase and use your own Devin subscription. Existing slots keep their earlier arrangement.
  2. The operator enables this pilot on your slot. You sign in to your own account through the official Devin CLI on that slot. Never send your credentials to the operator.
  3. Wait for Devin ready after account and model verification. If setup is required, use the setup guide on your slot card.
  4. Open Connection settings. Choose Devin · Claude agent under Model provider, select that one slot and save. Your Fleet API address and key stay the same when you switch.
  5. Use the displayed Fleet connection settings in official Claude Code. This pilot uses Opus 5.5 at max effort: start with claude --model opus --effort max; other models or features may be rejected. Follow the connection instructions and approve local tools in Claude Code as usual.

One-click web sign-in is not supported yet. You need Claude Code locally; Devin runs on your slot. Devin is offered only after pilot enablement and slot verification.

已经显示 Devin 已就绪？打开我的槽位 → 在电脑上使用 Devin，依次更新 Fleet、保存连接、开始编程。首次连接且没有可用 Fleet 配对的电脑，可改用手动连接设置。

  1. 打开浏览可用槽位，核对月费、确认购买，并使用你自己的 Devin 订阅。已有槽位保留原有安排。
  2. 运营方先在槽位上启用试点。你再通过槽位上的官方 Devin CLI 登录自己的账号，请勿把登录凭据发给运营方。
  3. 账号和模型验证后，等待显示 Devin 已就绪。如果提示需要配置，请打开槽位卡片上的配置指南。
  4. 打开连接设置，在模型服务中选择 Devin · Claude 智能体，只选这个槽位并保存。切换时 Fleet API 地址和密钥保持不变。
  5. 把页面提供的 Fleet 连接配置用于官方 Claude Code。试点使用 Opus 5.5 和 max 思考强度，请用 claude --model opus --effort max 启动；其他模型或功能可能被拒绝。按连接说明操作，照常在 Claude Code 中批准本地工具操作。

目前还不支持网页一键登录。本地只需使用 Claude Code，Devin 在你的槽位上运行。试点启用且槽位验证后，才会显示 Devin 选项。
