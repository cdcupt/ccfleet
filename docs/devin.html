Why we are evaluating Devin为什么评估 Devin

Devin is an operator-enabled pilot. Your account page offers it only after your own slot has been verified. Anthropic remains the default.

Devin 是由运营方明确启用的试点。只有自有节点通过验证后，你的账号页面才会提供这个选择。Anthropic 仍为默认服务。

One client, a possible new provider同一个客户端，增加一种提供商选择

We chose Devin for this pilot because it offers Claude models with a monthly subscription. You keep typing in official Claude Code on your computer. Fleet connects it to your own Devin CLI on your assigned slot.

我们选择 Devin 做试点，因为它提供 Claude 模型和月费订阅。你继续在自己电脑上的官方 Claude Code里输入需求，Fleet 把它连接到分配给你的节点上的自有 Devin CLI。

How it works它怎样工作

The Fleet API address and key token stay the same; the website provider setting chooses Anthropic or Devin. An internal MCP bridge carries tool requests back to Claude Code. Read, Edit and Bash run on your computer with Claude Code’s permissions.

Fleet API 地址和密钥保持不变，网站的提供商设置选择 Anthropic 或 Devin。内部 MCP 桥把工具请求送回 Claude Code，Read、Edit 和 Bash 由你的电脑执行，并遵守 Claude Code 的权限控制。

What the pilot proved试点验证了什么

An owner-pilot check through the public Fleet endpoint used Read, Edit and Bash and passed three local tests. All four streamed replies were verified as Opus 5.5 Max. Check your account page for current provider readiness.

This is native-agent compatibility mode: visible system instructions and history become labeled context for Devin CLI; its own harness instructions still apply. Images, documents, prior thinking blocks and other unsupported features reject before launch. count_tokens is unsupported. max_tokens is passed as context, not an enforced output or spending cap. Universal Claude Code parity is unverified.

Privacy: Saved files and local Claude Code history stay on your computer. File contents you send, selected context, replies and tool handoff records may also be stored on your slot by native Devin. Machine administrators (root) can read those records. They may remain until the slot is cleared; no retention period is guaranteed.

自有账号试点通过公开 Fleet 入口，使用 Read、Edit 和 Bash，通过了三个本地测试。四次流式回复均核实为 Opus 5.5 Max。连接前请查看账号页面上的服务就绪状态。

这是原生智能体兼容模式：可见的系统指令和历史记录作为带标签的上下文交给 Devin CLI，其自身运行框架的指令仍然生效。图片、文档、历史思考块等不支持的功能会在启动前拒绝；不支持 count_tokens。max_tokens 仅作为上下文传入，不是强制的输出或费用上限。尚未验证完整的 Claude Code 功能等价性。

隐私：保存的文件和本地 Claude Code 历史仍在你的电脑上。你发送的文件内容、选定上下文、回复及工具交接记录，也可能被原生 Devin 保存在槽位上。主机管理员（root）可以读取这些记录；记录可能保留到槽位清理时，不保证具体保留期限。

Use Devin with Claude Code怎样用 Claude Code 连接 Devin

Already Devin ready? Go straight to Connection settings.

  1. Open Browse available slots, claim a priced slot and use your own Devin subscription.
  2. The operator enables this pilot on your slot. You sign in to your own account through the official Devin CLI on that slot. Never send your credentials to the operator.
  3. Wait for Devin ready after account and model verification. If setup is required, use the setup guide on your slot card.
  4. Open Connection settings. Choose Devin · Claude agent under Model provider, select that one slot and save. Your Fleet API address and key stay the same when you switch.
  5. Use the displayed Fleet connection settings in official Claude Code. This pilot uses Opus 5.5 at max effort: start with claude --model opus --effort max; other models or features may be rejected. Follow the connection instructions and approve local tools in Claude Code as usual.

One-click web sign-in is not supported yet. You need Claude Code locally; Devin runs on your slot. Devin is offered only after pilot enablement and slot verification.

已经显示 Devin 已就绪？直接打开连接设置即可。

  1. 打开浏览可用槽位，领取已定价的槽位，使用你自己的 Devin 订阅。
  2. 运营方先在槽位上启用试点。你再通过槽位上的官方 Devin CLI 登录自己的账号，请勿把登录凭据发给运营方。
  3. 账号和模型验证后，等待显示 Devin 已就绪。如果提示需要配置，请打开槽位卡片上的配置指南。
  4. 打开连接设置，在模型服务中选择 Devin · Claude 智能体，只选这个槽位并保存。切换时 Fleet API 地址和密钥保持不变。
  5. 把页面提供的 Fleet 连接配置用于官方 Claude Code。试点使用 Opus 5.5 和 max 思考强度，请用 claude --model opus --effort max 启动；其他模型或功能可能被拒绝。按连接说明操作，照常在 Claude Code 中批准本地工具操作。

目前还不支持网页一键登录。本地只需使用 Claude Code，Devin 在你的槽位上运行。试点启用且槽位验证后，才会显示 Devin 选项。

A bundle needs permission打包销售需要授权

Each owner uses their own account on one node; there is no operator account pool. Reselling Devin access requires written reseller or partner permission from Cognition. Its standard policy prohibits resale and account sharing. Reseller permission has not been obtained; no Devin package is for sale.

每位用户在一个节点上使用自己的账号，不使用运营方账号池。转售 Devin 访问权必须先取得Cognition 的书面经销或合作授权。标准政策禁止转售和共享账号。转售授权尚未取得，目前没有在售的 Devin 套餐。
