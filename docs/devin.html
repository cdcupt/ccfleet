Why we are evaluating Devin为什么评估 Devin

Not yet verified in Fleet. CC Fleet currently supports Anthropic only. A Devin provider connection is unverified, and no Devin provider selection is active on the website.

尚未在 Fleet 验证，暂未开放。CC Fleet 当前只支持 Anthropic。Devin 提供商连接尚未验证，网站也尚未开放 Devin 提供商选择。

One client, a possible new provider同一个客户端，增加一种提供商选择

We are evaluating Devin as a third subscription option because it offers Claude models and a monthly base fee. The goal is to keep using official Claude Code, with the model provider chosen on the Fleet website.

Devin 提供 Claude 模型和基础月费订阅，因此我们将它作为第三种订阅选择来评估。目标是继续使用官方 Claude Code，并在 Fleet 网站选择模型提供商。

The route we want我们希望实现的路线

You would keep the same Fleet API address. Your website setting would choose Anthropic or Devin for model requests.

你将继续使用同一个 Fleet API 地址，由网站设置决定模型请求走 Anthropic 还是 Devin。

What must be verified first接入前要验证什么

Claude-model support in Devin CLI does not prove Claude Code compatibility. Its session API is another interface. Cognition’s published OpenCode integration provides a candidate model connection. Fleet would need translation between its Messages API and the integration’s OpenAI-compatible format.

Devin CLI 支持 Claude 模型，并不能证明它兼容 Claude Code。Devin 的会话 API也是另一种接口。Cognition 发布的 OpenCode 集成提供了一条可评估的模型连接路径。Fleet 需要在自己的 Messages API 与该集成使用的 OpenAI 兼容格式之间做转换。

Before activation, we must verify the request interface, streaming replies, tool use, authentication and subscription billing against Claude Code’s gateway requirements.

开放前必须依据 Claude Code 网关要求，验证请求接口、流式回复、工具使用、认证，以及订阅如何计费。

Price is only part of the decision价格只是判断的一部分

Checked October 18, 2026: Devin lists Pro at US$20/month and Max at US$200/month. Both are single-user plans with usage quotas; extra usage can cost more. This does not prove those subscriptions would cover Fleet model requests. An existing Claude subscription may be cheaper.

2026 年 10 月 18 日核对：Devin Pro 每月 20 美元，Max 每月 200 美元。两者均为单用户订阅，有用量额度，额外用量可能另收费。这不能证明订阅可以支付 Fleet 的模型请求。已有的 Claude 订阅可能更省钱。

A bundle needs permission打包销售需要授权

Reselling Devin access requires written reseller or partner permission from Cognition. Its standard policy prohibits resale and account sharing. No Devin package is for sale.

转售 Devin 访问权必须先取得Cognition 的书面经销或合作授权。标准政策禁止转售和共享账号。目前没有在售的 Devin 套餐。
