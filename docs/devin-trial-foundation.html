Try Devin from your local Claude Code

直接在电脑上的 Claude Code 中试用 Devin，无需购买槽位或登录 Devin。

Implementation prepared; off by default. This source adds the account page, trial-only keys, trusted admission and a dedicated native worker. It does not provision credentials, enable a live service or establish provider permission. Root must complete launch review and real native/Claude Code checks before enabling it. Paid private slots continue to use their owner's provider login.

Three steps

  1. Sign in to Fleet with Google, then open Try Devin.
  2. Create your trial key. Copy the displayed command into a terminal on your own computer with Claude Code installed. It selects the trial endpoint and the fixed claude-opus-5-5 model. No new app or Fleet slot is needed.
  3. Keep using that command/key on later days. The key lasts 30 days and can be revoked at any time. Replacing it revokes the previous key. Each account has its own allowance; your local Claude Code keeps your conversation history.

登录 Fleet →「试用 Devin」→ 创建试用密钥 → 在本地终端粘贴命令。密钥有效期 30 天，跨每日重置继续有效，可随时撤销；更换密钥会撤销旧密钥。无需购买槽位、登录 Devin 或安装另一款应用。

Privacy and isolation

The optional trial uses a Fleet-managed provider account. That is an explicit exception to the private-slot model, where customers bring their own provider account. The trial key grants only trial access; it cannot select or claim an owner's slot, fetch a provider credential or enter the paid-slot gateway. Local tools still run in your Claude Code with its permissions; native filesystem/shell/web/delegation tools stay disabled on the worker.

Each turn receives a fresh private HOME and state directory containing exactly a credential-only snapshot and two already pinned tool-disabled configuration files. No old session/history directory is copied. After owned native processes are confirmed stopped and the accounting outcome (complete usage or the conservative cache-only hold) is verified, the entire per-turn tree—including native attempt/result/history artifacts—is deleted before the global worker is released. A single private, bounded diagnostic summary survives cleanup: time, static failure code, cleanup/model-proof flags and token-field validity only. It contains no prompt, reply, history, identity, credentials or token amounts and is not a settlement receipt. If cleanup is unconfirmed, private artifacts are quarantined and the trial pauses. Administrators technically control the worker; provider retention follows provider terms. Do not send secrets. Your local Claude Code history remains on your computer.

限额试用使用 Fleet 管理的服务账号；付费私人槽位仍使用你自己的登录。试用密钥不能选择或领取他人的槽位，也无法获取服务商凭证。每轮只复制凭证及两份已固定、禁用原生工具的配置到全新目录，不复制旧历史；确认进程清理及计量结果（完整用量或保守额度保留）后，删除该轮全部目录。清理不确定时隔离产物并暂停。管理员在技术上控制机器，请勿提交秘密信息。

Fleet receives the original request. Before forwarding to Devin, the native bridge omits known private assistant reasoning and signatures while retaining visible text, local tool history and turn order; a bridge note replaces a private-only assistant turn. Reasoning continuity is lost and answers may change. Unknown or malformed content still rejects.

Fleet 会收到原始请求；转发给 Devin 前，原生桥接会省略已知格式的助手私有思考及签名，保留可见文本、本地工具历史和轮次顺序；只有私有思考的助手轮次会替换为明确的桥接说明。思考过程无法延续，回答可能因此改变。未知或格式错误的内容仍会被拒绝。
