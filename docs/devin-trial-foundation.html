How the daily Devin trial works每日 Devin 试用怎样工作

Claude Code is the app on your computer. Devin is the remote agent doing the thinking. Fleet connects them, checks who may use the trial, and keeps the usage ledger. Your files and tools stay local; the question and any included file contents or tool results travel to Fleet and Devin.

Claude Code 是你电脑上的应用，Devin 是远端负责思考的智能体。Fleet 负责连接两者、验证试用身份和记录用量。文件与工具留在本机；问题，以及请求中包含的文件内容和工具结果，会发送给 Fleet 和 Devin。

Compare the private-account and shared-trial architecture. The private gateway queue and trial single-worker admission are separate.对比私人账号与共享试用架构。私人网关队列与试用的单工作进程准入分别运行。

The hosted trial is enabled by the operator; the source default is still off. Installing this repository does not turn it on. CCFLEET_DEVIN_TRIAL_ENABLED=false is the default for each installation. The signed-in trial page shows the hosted service's current availability, remaining budgets and launch command. These are the current source limits; deployment settings and availability are separate from source defaults.

线上试用由运营方启用；源码默认仍为关闭。安装这个仓库不会自动开启试用。每个部署默认使用 CCFLEET_DEVIN_TRIAL_ENABLED=false。登录后的试用页显示线上服务当前是否可用、剩余额度和启动命令。本文记录当前源码的限额；部署状态与源码默认值是两回事。

Follow one question from start to finish跟着一个问题走完整个流程

For example, “read this file and explain it” may need one model turn to request Read, a local file read, then a second model turn to explain the result. A tool handoff and its continuation count as separate model turns. Each remote turn is a fresh process; continuity comes from the history Claude Code includes in the next request, not a reused remote session. Idle chats do not hold the worker.

The internal MCP bridge is a controlled mailbox for these declared tool calls. It freezes the list for that native turn and verifies the native call’s tool, session and ownership binding. Claude Code carries its matching result in the next request; the bridge does not keep a cross-turn result-pairing receipt. It does not give remote Devin a general shell on your computer. Replies and SSE are buffered until usage and cleanup checks finish, so they are not a promise of live token-by-token streaming.

例如，“读取这个文件并解释”可能先用一轮模型请求 Read，由本机读取文件，再用下一轮模型解释结果。工具交接和后续回复分别计为模型轮次。每轮远端进程都是新的；对话连续性来自 Claude Code 下一次请求所带的历史，而不是复用远端会话。空闲聊天不会占用工作进程。

内部 MCP 桥像一个受控信箱，只传递已声明的工具调用，为该轮固定工具清单，并核对原生调用的工具、会话及所有权绑定。Claude Code 在下一次请求中携带对应结果；桥接器不保留跨轮次的结果配对回执。它不会把本机的通用终端权限直接交给远端 Devin。回复和 SSE 会等到用量与清理检查完成后才返回，不保证逐 token 实时输出。

Which agent is answering?回答的是哪个智能体？

The interface is official Claude Code; the remote harness is native Devin, using the fixed claude-opus-5-5 route with the root-controlled max-effort policy. Devin may correctly introduce itself as Devin. A Claude-shaped API does not turn the native Devin harness into the Claude Code harness or provide every Claude feature. Fleet does not rewrite an agent's identity to hide this difference.

界面是官方 Claude Code，远端运行环境则是原生 Devin；路由固定为 claude-opus-5-5，使用由 root 策略控制的 max effort。Devin 自称 Devin 是正常的。兼容 Claude API 格式，不代表把 Devin 运行环境变成 Claude Code，也不代表支持 Claude 的全部功能。Fleet 不会改写智能体身份来掩盖这一区别。

Launch settings and your key启动设置与密钥

  1. Sign in to Fleet with a verified Google account and open Try Devin. No slot purchase or Devin login is needed.
  2. Create a trial key once, then copy the complete account-visible command into a local terminal with Claude Code installed. The command supplies the endpoint, your private trial key, model aliases and compatibility settings.
  3. Return to that signed-in page to copy the same active key after a refresh or language change. It lasts 30 days across daily resets. A GET does not rotate it. Explicit replacement revokes the old key immediately; revocation or expiry stops it. Older random keys cannot be redisplayed and need one explicit replacement to enable retrieval.

The default command includes --permission-mode bypassPermissions --disallowedTools WebSearch,WebFetch. Project instructions, compatible MCP servers and plugins load normally. Add the optional --safe-mode flag to temporarily disable customizations when troubleshooting. The default bypass permission mode lets local coding tools run without individual approval prompts; Claude Code may ask you to accept that mode at first launch. Saved settings are unchanged.

The command also sets ENABLE_TOOL_SEARCH=false CLAUDE_CODE_DISABLE_TERMINAL_TITLE=1 CLAUDE_CODE_DISABLE_THINKING=1 to avoid unsupported auxiliary Claude requests. These settings do not change the remote Devin model or its root-controlled thinking policy. To update a saved command, preserve its existing private key, add missing options, and relaunch Claude Code. No new key or Claude /login is needed.

  1. 使用已验证的 Google 账号登录 Fleet，打开试用 Devin，无需购买槽位或登录 Devin。
  2. 创建一次试用密钥，然后把账号页的完整命令粘贴到已安装 Claude Code 的本地终端。命令包含地址、你的私密试用密钥、模型别名和兼容设置。
  3. 刷新或切换语言后，仍可回到登录后的页面复制同一个有效密钥。密钥有效期为 30 天，可跨每日重置使用；GET 不会更换密钥。主动更换会立即撤销旧密钥，撤销或到期也会使其失效。旧版随机密钥无法重新显示，需要主动更换一次才能启用重新复制功能。

默认命令包含 --permission-mode bypassPermissions --disallowedTools WebSearch,WebFetch。项目指令、兼容的 MCP 服务及插件会正常加载。排查问题时，可添加可选的 --safe-mode 暂时关闭自定义配置。默认绕过权限模式允许本地编程工具无需逐次批准即可运行，首次启动时 Claude Code 可能要求确认。已保存的设置不会改变。

命令还设置 ENABLE_TOOL_SEARCH=false CLAUDE_CODE_DISABLE_TERMINAL_TITLE=1 CLAUDE_CODE_DISABLE_THINKING=1，避开不支持的 Claude 辅助请求。这些设置不会改变远端 Devin 模型或 root 控制的思考策略。更新已保存的命令时，保留原有私密密钥、补齐选项并重新启动 Claude Code；无需新密钥，也无需 Claude /login。

Local tools and hosted web tools are different本地工具与服务端网页工具不同

Read, Edit, Write and Bash are examples of tools Claude Code can execute on your computer. Compatible MCP tools can also be declared when customizations are enabled. A tool's name, description and object input schema are the contract sent to the native bridge.

Claude Code's built-in WebSearch and WebFetch make additional provider requests that this native route does not support. The launch command excludes them from the offered tool list. In particular, a plain outer WebSearch description is not the same as its nested Anthropic server-tool request. Extended server-side/deferred declarations remain an explicit 400 error; Fleet does not drop them or pretend they ran.

This is not a blanket ban on networking: compatible local tools or separately configured MCP tools can perform web work under their own behavior and permissions. Requests still need supported text/local-tool shapes and must fit the trial limits. Use Claude when you need its hosted built-ins. Images, documents, structured-output controls and other unsupported shapes fail before model execution.

Read、Edit、Write 和 Bash 都是 Claude Code 可在本机执行的工具。启用自定义配置时，也可声明兼容的 MCP 工具。发送给原生桥接的工具契约包含名称、说明和对象类型输入 schema。

Claude Code 内置 WebSearch 和 WebFetch 会额外发送此原生路由不支持的服务商请求，因此启动命令会从可用工具清单中排除它们。尤其是外层普通 WebSearch 工具说明，不等于它内部发送的 Anthropic 服务端工具请求。扩展的服务端或延迟加载声明仍会明确返回 400；Fleet 不会偷偷删除它们，也不会假装执行成功。

这不是全面禁止联网：兼容的本地工具或另行配置的 MCP 工具，仍可按各自行为与权限处理网页。请求仍须使用受支持的文本／本地工具格式，并符合试用限制。需要 Claude 托管的内置工具时，请使用 Claude。图片、文档、结构化输出控制等不支持的格式会在模型执行前被拒绝。

Web search. The hosted trial enables Devin's native web_search through a separate root-pinned capability. Ask Devin to find current public information and include sources. It does not use Claude's hosted WebSearch/WebFetch. Native file, shell, page-fetch and delegation tools stay blocked; compatible local tools can read pages and work on your files.

A slow turn should not stop your next question. If a five-minute timeout has verified model identity, valid partial token records and confirmed cleanup, Fleet keeps the full token reservation or the larger known subtotal, records an interrupted-turn hold, and releases the worker. The response remains a timeout, never a successful answer or complete usage claim. Actual usage may exceed the hold. Missing model/usage evidence, lost execution or uncertain cleanup still pauses for review. No failed inference request is automatically replayed.

网页搜索。线上试用通过独立的 root 固定能力启用 Devin 原生 web_search。可要求 Devin 查找最新公开信息并附上来源；它不会调用 Claude 托管的 WebSearch/WebFetch。原生文件、终端、网页抓取及委派工具仍关闭，兼容的本地工具可读取网页并处理你的文件。

慢一轮不应阻止下一问。若五分钟超时后模型身份已验证、拥有有效的部分 token 记录且全部清理完成，Fleet 保留整笔 token 预留或更大的已知部分，记录“中断轮次”保留额度并释放工作进程。响应仍为超时，不会伪装成成功回复或完整用量；实际用量可能超过保留额度。模型或用量证据缺失、执行失联或清理不确定仍须暂停审查。失败推理不会自动重放。

Several separate budgets, not one fuel gauge几种独立限额，不是一根油量条

Having tokens left does not guarantee another turn can start. Fleet checks all of these independent limits. Both personal and shared daily budgets reset at 00:00 UTC; replacing a key resets none of them.

The page's “Full-length turns covered now” is the smallest remaining turn, lease and full-runtime capacity across your account and the shared budget. It describes capacity before unused runtime is returned; later token usage and worker availability still apply. Fleet rejects known exhausted budgets before contacting the worker, then checks transactionally again after readiness so a race cannot bypass the limit.

Up to 20,000 remaining tokens are held before each model send. Complete trusted usage settles the actual total, including overshoot. If only cache-read metering is missing, a verified model, valid reply and confirmed full cleanup permit a conservative hold: the full reservation remains, or the larger known subtotal. The page shows those partial readings separately without double counting. Other users can use the released worker. max_tokens is context for Devin, not an upstream enforced output or spending cap.

Outside the verified clean-timeout policy above, if execution, model identity, required usage fields or cleanup is uncertain, Fleet retains the unknown reservation and pauses new work. Unknown holds are never automatically refunded or changed to zero. A daily reset creates a new day's budget; it does not clear a safety pause or certify old usage. A proven failure before any model request-frame write is different: its model-turn, runtime and allowance counters are refunded and a closed audit row remains. The separate API rate bucket still applies.

页面的“当前可覆盖的完整时限轮次”，取个人与全局剩余轮次、租约及完整运行时间容量中的最小值。它表示退回未用运行时间前的容量，后续仍需满足 token 额度及工作进程可用性。已知额度耗尽时，Fleet 会在联系工作进程前拒绝；就绪后还会在事务中重查，防止并发绕过限制。

每次发送模型请求前，先预留最多 20,000 剩余 token。完整可信用量按实际总数结算，超额也全部计入。只有缓存读取计量缺失时，须同时验证模型、回复有效且全部清理完成，才允许保守保留：保留完整预留额度，已知部分更大则保留更多。页面单独显示这些不完整读数，不重复相加；其他用户仍可使用释放后的工作进程。max_tokens 对 Devin 是上下文，不是上游强制的输出或费用上限。

除上述已验证并清理的超时保留策略外，执行情况、模型身份、必需用量字段或清理不确定时，Fleet 保留未知预留并暂停新任务。未知保留额度绝不自动退款或补成零。每日重置只建立新一天的额度，不会解除安全暂停，也不证明旧用量。若能证明模型请求帧尚未写入，则不同：会退回模型轮次、运行时间与额度计数，并留下已关闭的审计行；独立 API 速率额度仍适用。

Why the different clocks?为什么有几个不同的时钟？

Think of the runtime reservation as a temporary room booking. After verified settlement and cleanup, unused reserved seconds return to the daily runtime budget. The shorter deadlines stop real work; the longer envelopes leave room for startup, transport and cleanup. None of them gives the model extra thinking time.

运行时间预留像暂时预约房间；确认结算及清理后，未用的预留秒数会退回每日运行预算。较短的截止时间限制实际工作，较长的外层边界为启动、传输和清理留空间；它们不会额外延长模型思考时间。

Before opening the door, a separate checker verifies the account identity and asks whether the requested model is available. If the model-list command fails, one fresh account check can run within the same 90-second total deadline. Its time budget shrinks to leave room for cleanup; it sends no model request. If verification still fails, trial access stays unavailable. After a worker access-key update finishes, Fleet can revalidate this cycle's fresh account evidence when the owner, runtime, credential and source profile still match. BAD, old or mismatched evidence still refuses readiness.

开门前，独立检查器会核实账号身份，并确认所需模型可用。模型清单命令失败时，可在原有 90 秒总期限内重新做一次完整账号检查；第二次会缩短检查时间，为清理留出余量，不发送模型请求。仍无法验证时，试用保持不可用。工作进程的访问密钥更新完成后，若所有者、运行环境、凭证及来源配置仍一致，Fleet 可重新核验本轮刚取得的账号证据。BAD、过期或不匹配的证据仍会拒绝就绪。

400 — 格式不支持或过大请求在模型执行前被拒绝。例如扩展服务端工具不受支持，请求 JSON（含工具／历史）最多 2 MiB。调整请求或启动选项；API 速率额度仍可能已被使用。

Busy/rate errors have Retry-After; daily-budget errors explain the UTC reset instead. Model responses use x-should-retry: false, including errors, so no ambiguous model send is automatically replayed. This is especially important across tool continuations: one visible user question can involve several independent model turns.

忙碌／速率错误提供 Retry-After；每日额度错误则说明 UTC 重置时间。模型响应（包括错误）设置 x-should-retry: false，避免自动重放发送情况不明确的模型请求。工具续接时尤其重要：用户看到的一个问题可能包含多个独立模型轮次。

Privacy and isolation隐私与隔离

The optional trial uses a Fleet-managed provider account. Paid private slots keep their own owner/provider sign-in. A trial key grants only trial access: it cannot select or claim an owner's slot, fetch a provider credential, or enter the paid-slot gateway. Local tools execute in Claude Code; native filesystem, shell, web-fetch and delegation tools remain disabled on the worker.

Each turn receives a fresh private HOME and state directory containing exactly a credential-only snapshot and two already pinned tool-disabled configuration files. No old session/history directory is copied. After owned native processes are confirmed stopped and the accounting outcome (complete usage or a conservative partial-usage hold) is verified, the entire per-turn tree—including native attempt/result/history artifacts—is deleted before the global worker is released. A single private, bounded diagnostic summary survives cleanup: time, static failure code, cleanup/model-proof flags and token-field validity only. It contains no prompt, reply, history, identity, credentials or token amounts and is not a settlement receipt. If cleanup is unconfirmed, private artifacts are quarantined and the trial pauses. Administrators technically control the worker; provider retention follows provider terms. Do not send secrets. Your local Claude Code history remains on your computer.

Fleet receives the original request. Before forwarding to Devin, the native bridge omits known private assistant reasoning and signatures while retaining visible text, local tool history and turn order; a bridge note replaces a private-only assistant turn. Reasoning continuity is lost and answers may change. Unknown or malformed content still rejects.

Recoverable trial keys are derived with domain-separated HMAC-SHA256 from the deployment secret, account ID and a random versioned key ID; the access database stores only the existing token hash and metadata. Authenticated retrieval checks account ownership, expiry, revocation and the derived hash. Rotating the deployment secret can make retrieval unavailable without revoking a previously saved command; a GET never replaces it. Key pages are private, no-store and no-referrer.

The dedicated trial ledger rejects product databases, incompatible schemas and unknown persisted limit profiles. It stores only local IDs, hashes, timestamps, fixed statuses and integer counters. Only exact reviewed predecessor profiles can migrate to expanded limits, transactionally; existing usage, runtime, holds, sessions, pause state and history are preserved. New source files do not change production financial Store rows, owner gateway grants, client bytes or enroll users automatically.
