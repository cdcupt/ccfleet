Run the stock Antigravity CLI with the model session on your paired slot

This macOS preview runs the real CCFleet relay with two unmodified Google Antigravity CLI processes. The client keeps the repository, the shell and every permission decision; the paired private Mac runs the model session under its own Google sign-in and has no copy of your project. The slot's model can only use the client's bridged tools (read_file, write_file, edit_file, run_command) and cannot execute anything on the slot itself.

Run the terminal

Install Google's agy on this Mac and pair it with your private slot once:

./laptop/ccfleet pair gemini
./laptop/ccfleet gemini --project /path/to/your/repo

ccfleet gemini now runs this terminal by default. The previous local editor session, where this Mac runs the model and the slot only supplies the workspace tools, stays available as ccfleet gemini --editor; T3 Code's --acp command is unchanged.

Inside the stock Antigravity interface, review each operation as it arrives: allow a read, accept or reject an edit, allow a command. A rejection keeps the file unchanged, and the slot receives the denial in the same remote conversation. Turns are transcript-verified, interruptions release the held call, and a repeated request replays the recorded result instead of re-running anything.

Scripted verification

The signed --native-check command remains available: it exercises four fixed operations with deterministic model responses and consumes no Google model credits. Its model responses are scripted; a successful run does not by itself establish support for consumer-plan headless wrappers.

Consumer-plan risk — read this

Google's Antigravity FAQ and Terms of Service prohibit third-party wrappers on consumer plans (“Using third-party software, tools, or services to access Antigravity is a violation of our Terms of Service”; “Wrapping agy inside third-party coding agents or applications … is not supported under consumer plans”). Using this terminal on a Pro/Ultra account can put that account at risk, including suspension. The operator accepted that risk for the internal alpha, one person per account and no pooling, and this disclosure travels with the feature; a separately billed Gemini API backend is the compliant alternative.

Exercised with agy 1.5.14 and 1.5.16 on macOS: the four operations plus denial propagation pass over the two-CLI bridge with real subscription inference (2026-11-24).
