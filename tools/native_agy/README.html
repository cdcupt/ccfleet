Test native agy through your private slot

This opt-in macOS preview exercises the real CCFleet relay and two unmodified Google Antigravity CLI processes. Its model responses are scripted. Both CLIs use disposable profiles and the client creates a temporary Git repository. The check uses no Google model credits.

Run the paired test

Download the preview ZIP from this prerelease, unpack it, and open Terminal in the extracted ccfleet-native-check folder. Install Google’s agy on the client Mac first. The private Mac slot must have the native-check handler. If this client already has a Gemini workspace pairing for that slot, run the check directly. To pair it first, use your CCFleet Gemini setup code with the bundled launcher.

./laptop/ccfleet pair gemini
./laptop/ccfleet gemini --native-check --project /path/to/your/repo

Replace the path with an existing local directory. If you have several slots, specify the intended paired slot with --slot. In agy, trust the disposable folder, allow the marker read if prompted, accept approved.txt, allow git rev-parse --show-toplevel, and reject denied.txt. Expect PASS only after the slot receives the denial. A timed-out or interrupted run ends and can be restarted in a fresh fixture. This preview was exercised with agy 1.5.14.

Test both roles locally

python3 ccfleet_agent/gemini_native_check.py loopback .

This mode uses a local pipe. Use the paired command above to test ccfleet.io. This preview verifies tool execution and permissions. A successful run does not establish support for consumer-plan headless wrappers. See Google’s Antigravity FAQ.
