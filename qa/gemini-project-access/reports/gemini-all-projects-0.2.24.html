One Gemini grant across projects

The signed public updater upgraded CCFleet from 0.2.23 to 0.2.24. An existing Gemini pairing works across the terminal, T3, Orca and Herdr.

Enable once on your Mac

ccfleet update
cd ~
ccfleet gemini --full-access

Type ENABLE once at initial setup. The command exits. Launch CCFleet Gemini in a development project, or start at home and send /workspace ~/code/app. Send the command again to change projects in the same conversation. Ordinary project work runs without CCFleet approval prompts; unavailable actions return an error. Revoke from home with ccfleet gemini --revoke-full-access.
