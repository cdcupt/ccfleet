CCFleet 0.2.23 project access

The signed public updater installed 0.2.23 from 0.2.22. The local grant belongs to one checkout on the connecting Mac.

Enable it

In a terminal in the project directory, run the following commands. Check the displayed project path and publishing destination before typing ENABLE.

ccfleet update
ccfleet gemini --full-access

Open ccfleet gemini or select CCFleet Gemini in T3. To revoke access for that checkout, run ccfleet gemini --revoke-full-access in the same directory.

Publishing and test scope
